# 技术调研AI提示模板

## 模板说明
用于技术调研和趋势分析的AI提示模板，结合vibe-tools工具进行深度研究。

## 使用场景
- 技术选型决策
- 最新技术趋势研究
- 竞品分析
- 解决方案搜索

## 提示模板

### 基础技术调研
```
请使用以下工具进行技术调研：

1. 使用 vibe-tools web 搜索最新的技术趋势和最佳实践
2. 使用 vibe-tools repo 分析相关开源项目的实现
3. 使用 vibe-tools plan 制定技术选型方案

调研主题：[具体技术或问题]
目标：[明确的研究目标]
```

### 深度技术分析
```
请进行深度技术分析：

1. 使用 vibe-tools web 研究技术背景和发展趋势
2. 使用 vibe-tools repo 分析现有项目的技术栈
3. 使用 vibe-tools plan 制定技术升级或迁移方案
4. 使用 vibe-tools doc 生成技术分析报告

分析主题：[具体技术领域]
项目背景：[当前项目情况]
分析目标：[期望的分析结果]
```

### 竞品技术分析
```
请进行竞品技术分析：

1. 使用 vibe-tools web 搜索竞品技术栈和架构
2. 使用 vibe-tools repo 分析竞品开源项目
3. 使用 vibe-tools plan 制定技术对比方案
4. 使用 vibe-tools doc 生成竞品分析报告

竞品：[具体竞品名称]
分析维度：[技术栈、架构、性能等]
对比目标：[我们的技术方案]
```

## 输出格式

### 技术调研报告
```markdown
# 技术调研报告

## 调研主题
[技术或问题描述]

## 技术趋势
- 最新发展动态
- 社区活跃度
- 技术成熟度

## 技术选型
- 推荐方案
- 替代方案
- 风险评估

## 实施建议
- 实施步骤
- 注意事项
- 最佳实践
```

### 技术分析报告
```markdown
# 技术分析报告

## 分析背景
[项目背景和技术现状]

## 技术分析
- 技术栈分析
- 架构设计分析
- 性能分析

## 优化建议
- 技术优化方案
- 架构改进建议
- 性能提升策略

## 实施计划
- 分阶段实施
- 风险评估
- 成功指标
```

## 使用示例

### 示例1：React 18升级调研
```
请使用以下工具进行React 18升级调研：

1. 使用 vibe-tools web 搜索"React 18新特性和升级指南"
2. 使用 vibe-tools repo 分析"现有React项目的技术栈和依赖"
3. 使用 vibe-tools plan 制定"React 18升级方案"
4. 使用 vibe-tools doc 生成"React 18升级报告"

项目背景：当前使用React 17，需要升级到React 18
升级目标：提升性能，使用新特性，保持兼容性
```

### 示例2：微服务架构设计
```
请进行微服务架构设计：

1. 使用 vibe-tools web 研究"微服务架构最佳实践"
2. 使用 vibe-tools repo 分析"现有单体应用的架构"
3. 使用 vibe-tools plan 制定"微服务拆分方案"
4. 使用 vibe-tools doc 生成"微服务架构设计文档"

项目背景：大型单体应用需要拆分为微服务
设计目标：提高可扩展性，降低耦合度，提升开发效率
```

### 示例3：性能优化分析
```
请进行应用性能优化分析：

1. 使用 vibe-tools web 研究"前端性能优化最佳实践"
2. 使用 vibe-tools repo 分析"现有应用的性能瓶颈"
3. 使用 vibe-tools plan 制定"性能优化方案"
4. 使用 vibe-tools browser 测试"优化后的性能表现"

项目背景：应用响应慢，用户体验差
优化目标：提升页面加载速度，改善用户体验
```

## 注意事项

1. **明确调研目标** - 清楚定义要研究的技术或问题
2. **提供项目背景** - 说明当前项目的技术现状
3. **设定分析维度** - 明确从哪些角度进行分析
4. **期望输出结果** - 说明期望得到什么样的分析结果
5. **结合实际情况** - 考虑项目的实际约束和需求
