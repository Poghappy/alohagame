# 项目管理AI提示模板

## 模板说明
用于项目管理和团队协作的AI提示模板，结合vibe-tools工具进行完整的项目管理流程。

## 使用场景
- 项目启动
- 进度跟踪
- 任务管理
- 团队协作

## 提示模板

### 项目启动
```
请使用AI团队协作进行项目启动：

**项目总监** - 项目规划：
1. 使用 vibe-tools web 研究项目相关技术和市场趋势
2. 使用 vibe-tools plan 制定项目整体规划
3. 使用 vibe-tools doc 生成项目需求文档

**技术架构师** - 技术规划：
4. 使用 vibe-tools repo 分析现有技术栈
5. 使用 vibe-tools plan 制定技术架构方案
6. 使用 vibe-tools doc 生成技术设计文档

**全栈开发** - 开发规划：
7. 使用 vibe-tools repo 分析开发环境
8. 使用 vibe-tools plan 制定开发计划
9. 使用 vibe-tools github 创建项目仓库

**测试工程师** - 测试规划：
10. 使用 vibe-tools browser 设计测试环境
11. 使用 vibe-tools plan 制定测试策略
12. 使用 vibe-tools doc 生成测试计划

**DevOps工程师** - 环境规划：
13. 使用 vibe-tools github 配置CI/CD
14. 使用 vibe-tools linear 创建项目任务
15. 使用 vibe-tools doc 生成部署文档

项目描述：[项目背景和目标]
技术要求：[技术栈和架构要求]
时间安排：[项目时间节点]
团队规模：[开发团队规模]
```

## 注意事项

1. **明确项目目标** - 清楚定义项目成功标准
2. **合理分配资源** - 根据团队能力分配任务
3. **建立沟通机制** - 确保团队协作顺畅
4. **监控项目风险** - 及时发现和解决问题
5. **持续优化流程** - 根据实际情况调整管理策略
