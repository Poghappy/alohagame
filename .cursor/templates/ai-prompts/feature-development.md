# 功能开发AI提示模板

## 模板说明
用于功能开发和实现的AI提示模板，结合vibe-tools工具进行完整的开发流程。

## 使用场景
- 新功能开发
- 功能优化
- Bug修复
- 代码重构

## 提示模板

### 新功能开发
```
请使用AI团队协作进行新功能开发：

**项目总监** - 需求分析：
1. 使用 vibe-tools web 研究功能的最佳实践和实现方案
2. 使用 vibe-tools plan 制定功能开发计划

**技术架构师** - 架构设计：
3. 使用 vibe-tools repo 分析现有代码架构
4. 使用 vibe-tools plan 设计功能的技术架构

**全栈开发** - 功能实现：
5. 使用 vibe-tools repo 分析相关代码实现
6. 使用 vibe-tools plan 制定具体的实现步骤

**测试工程师** - 测试验证：
7. 使用 vibe-tools browser 进行功能测试
8. 使用 vibe-tools test 进行自动化测试

**DevOps工程师** - 部署管理：
9. 使用 vibe-tools github 管理代码仓库
10. 使用 vibe-tools linear 跟踪开发进度

功能描述：[具体功能描述]
技术要求：[技术栈和约束]
预期结果：[期望的功能效果]
```

## 使用示例

### 示例1：用户认证功能开发
```
请使用AI团队协作开发用户认证功能：

功能描述：实现用户登录、注册、密码重置功能
技术要求：使用JWT认证，支持OAuth2，安全性要求高
预期结果：用户可以通过多种方式安全登录系统

请按照AI团队协作流程进行开发。
```

### 示例2：API性能优化
```
请使用AI团队协作优化API性能：

性能问题：API响应时间超过2秒，用户投诉较多
优化目标：响应时间降低到500ms以下
技术约束：使用Node.js + Express，不能改变数据库

请按照AI团队协作流程进行优化。
```

### 示例3：前端组件重构
```
请使用AI团队协作重构前端组件：

组件描述：用户列表组件，当前代码复杂，难以维护
重构目标：提高代码可读性，增强可复用性
技术栈：React + TypeScript + Ant Design

请按照AI团队协作流程进行重构。
```

## 注意事项

1. **明确功能需求** - 清楚描述要实现的功能
2. **设定技术约束** - 说明技术栈和架构限制
3. **定义成功标准** - 明确功能验收标准
4. **考虑测试策略** - 制定完整的测试方案
5. **规划部署流程** - 考虑部署和回滚策略
