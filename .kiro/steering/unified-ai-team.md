# 统一AI团队协作规则

## 团队概述

这是一个整合了cursor-workspace和vibe-tools优势的统一AI团队，提供从需求分析到项目交付的完整解决方案。

### 核心优势整合

#### 来自cursor-workspace的优势：
- **零操心交付** - 完全自动化的项目交付流程
- **智能解决方案评估** - 自动评估技术选型和复用可行性
- **学习管理系统** - 持续的技术学习和技能提升
- **团队协作流程** - 完整的团队协作和沟通机制

#### 来自vibe-tools的优势：
- **AI工具集成** - 完整的AI工具链集成
- **多模型协作** - Perplexity + Gemini + OpenAI + Stagehand
- **智能工作流程** - 自动化的开发工作流程
- **质量保证体系** - 端到端的测试和验证

## 统一工作流程

### 项目启动阶段
1. **项目总监** 使用 `vibe-tools web` 进行技术调研
2. **解决方案评估系统** 自动评估技术选型
3. **技术架构师** 使用 `vibe-tools repo` 分析现有架构
4. **全栈开发** 使用 `vibe-tools plan` 制定实现方案
5. **零操心交付系统** 自动配置项目环境

### 开发阶段
1. **全栈开发** 使用 `vibe-tools repo` 进行代码开发
2. **学习系统** 持续跟踪技能提升
3. **测试工程师** 使用 `vibe-tools browser` 进行自动化测试
4. **技术架构师** 使用 `vibe-tools repo` 进行代码审查
5. **DevOps工程师** 使用 `vibe-tools github` 管理代码仓库

### 测试阶段
1. **测试工程师** 使用 `vibe-tools browser` 进行端到端测试
2. **全栈开发** 使用 `vibe-tools repo` 修复Bug和优化代码
3. **技术架构师** 使用 `vibe-tools repo` 进行性能优化
4. **项目总监** 使用 `vibe-tools doc` 生成测试报告
5. **质量保证系统** 自动验证交付标准

### 部署阶段
1. **DevOps工程师** 使用 `vibe-tools github` 管理部署流程
2. **测试工程师** 使用 `vibe-tools browser` 进行生产环境测试
3. **项目总监** 使用 `vibe-tools linear` 跟踪项目进度
4. **技术架构师** 使用 `vibe-tools doc` 生成部署文档
5. **零操心交付系统** 确保部署成功

## 配置说明

确保配置以下API密钥：
- `OPENAI_API_KEY` - OpenAI API密钥
- `ANTHROPIC_API_KEY` - Anthropic API密钥
- `GEMINI_API_KEY` - Google Gemini API密钥
- `PERPLEXITY_API_KEY` - Perplexity API密钥
- `GITHUB_TOKEN` - GitHub访问令牌
- `LINEAR_API_KEY` - Linear API密钥
