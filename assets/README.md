## 📋 使用建议

### Web 应用
- **Logo**: 使用 `alohagame_logo_256.png` 或 `alohagame_logo_128.png`
- **Favicon**: 使用 `alohagame_favicon_32.png` 或 `alohagame_favicon_16.png`
- **社交媒体**: 使用 `alohagame_social_1200x630.png`

### 移动应用
- **应用图标**: 使用 `alohagame_icon_512.png` (iOS) 或 `alohagame_icon_192.png` (Android)
- **启动画面**: 使用 `alohagame_banner_1920x1080.png`

### 文档和演示
- **横幅**: 使用 `alohagame_banner_1200x600.png`
- **封面**: 使用 `alohagame_social_1080x1080.png`

## 🛠️ 生成工具

这些素材使用以下 MCP 服务器生成：
- **Media Processor** - 图片缩放、格式转换、效果处理
- **ImageMagick** - 高级图片处理
- **FFmpeg** - 视频和图片处理
